  • Embedding / Providing CSS

    There are three different ways to apply styles in HTML:
    1. Internal CSS (Embedded Stylesheet): CSS is written inside the <style> tag in the HTML file.
    2. External CSS: CSS is written in a separate .css file and linked to the HTML file.
    3. Inline CSS: CSS is written directly inside an element’s style attribute.

    Internal / Embedded CSS

    Example: 👇
    <head>
    <style>
       p{
        color: red;
       }
    </style>
    </head>
    <body>
       <p>Lorem ipsum dolor sit, amet consectetur adipisicing.</p>
       <p>Lorem ipsum dolor sit, amet consectetur adipisicing.</p>
    </body>

    This process is very limited. If we have multiple HTML pages, the styling will only affect the current page, not the others. For example, if you later want to change the color of all paragraphs across the whole website, this method will only update the paragraphs on the current page. You would need to manually edit every page, which is not recommended.

    External CSS

    File separation is very important in computer science. This idea is called Separation of Concerns.
    It means keeping different responsibilities in different files. For example:
    - Write HTML in one file.
    - Write CSS in another file.
    Both are different languages with different purposes.
    Think of it like a supermarket: there are separate sections for fruits, vegetables, clothes, and electronics. If everything was mixed together in one big section, it would be very hard to find what you need.
    That’s why we separate files in programming so things stay organized and easier to manage.

    Create a new external file named style.css and write your CSS code in it. Then, link this file to your HTML document inside the <head> section using:
    <link rel="stylesheet" href="style.css">
    Now, whenever you make changes in the style.css file, those changes will automatically show up in your HTML page.
    The best part is that you can use the same CSS file for multiple HTML pages. This makes it easier to style your entire website from one stylesheet.

    CSS Syntax

    h1{
       color: red;
    }
    In CSS, we first target an HTML element. Targeting an element is called a selector in above there is h1 as a selector.
    There are different types of selectors (we’ll learn them in upcoming lessons).
    After the selector, we use curly braces {}. This part is called the selector body. Inside it, we write:
       - A property: tells what style we want to change (example: color).
       - A value: tells the setting for that property (example: red).
    Together, the property and value make a declaration, written like this:
    color: red;
    Each declaration ends with a semicolon (;).
    p {
       color: red;
       background-color: black;
    }
    This means: All <p> (paragraphs) will have red text & black background.

    Inline CSS

    We use inline CSS by writing styles directly inside an HTML element. For example:
    <p style="color: green; background-color: black;">

    Lorem ipsum dolor sit amet consectetur, adipisicing elit. Facilis, veniam.

    </p>
    However, using inline CSS is not a good practice because:
       - It makes the code messy and hard to maintain.
      - It breaks the “separation of concerns” principle (HTML should handle structure, CSS should handle styling).

    Cascading

    If we use multiple styles (inline, internal, and external CSS) in one HTML file, remember:
    ~~~ The style that is closest to the element will be applied.
    In this example, the inline style is the closest to the paragraph, so it will override other styles.
    This concept is called cascading, which is why the language is named Cascading Style Sheets (CSS).

    Comments✍️

    What is a comment: A comment is a note you write in your CSS code for yourself or other developers.
    It does not run in the browser.
    Why use comments?
    📝 To explain your code
    📝 To organize sections of your CSS
    📝 To temporarily disable a CSS rule
    How to write a comment in CSS?
    /* This is a CSS comment */
    p {
          color: red; /* This makes the text red */
    }
        - Think of comments as sticky notes inside your code helpful for remembering why you wrote something.

    Class Selector

    We can select (target) an element using its class in CSS.
    A class is written with a dot (.) followed by the class name.
    CSS code:
    .product {
       border: 5px solid red;
    }
    HTML code:
    <section id="products">
       <article class="product"></article>
       <article class="product"></article>

    Attribute Selector

    We can also select elements in CSS using attributes.
    This method isn’t very common, but it’s important to know because you might see it in other people’s code.
    CSS code:
    a[target] {
       color: red;
    }
    a[href="https://google.com"] {
       color: black;
    }
    HTML Code:
    <a href="https://google.com" target="_blank">Google</a>

    Types of Attribute Selectors

    Exact Match Selects an element only if the attribute matches exactly.
    a[href="https://google.com"] {
       color: black;
    }
    Contains a Word Selects if the attribute contains a specific word.
    a[href*="google"] {
       color: red;
    }
    Here, if the word google is found anywhere inside href, it will be selected.
    Starts With Selects if the attribute value starts with a certain word.
    a[href^="https"] {
       color: red;
    }
    This will select all links that start with https. Ends With Selects if the attribute value ends with a certain word.
    a[href$=".com"] {
       color: red;
    }
    This will select all links that end with .com.
    Combine Multiple Conditions You can combine different checks together. a[href^="https"][href$=".com"] {
       color: red;
    }
    This will select all links that start with https and also end with .com.

    In short: Attribute selectors let you target elements based on their attributes (like href, target, id, etc.).

    Direct child Selector

    What if we only want to select the paragraph inside the <section> element that has the ID products?
    - We could give that paragraph its own id or class, but sometimes if the parent already has an id, we don’t need to make the code more complicated. In that case, we can use a relational selector.
    - The > (greater-than) symbol in CSS means “direct child.” So if we write #products > p, it will select only the paragraph that is a direct child of the section with the ID products, not the paragraphs inside deeper elements like <article>.
    CSS CODE:
    #products > p {
        color: red;
    }
    HTML CODE:
    <section id="products">
       <p>     Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    <article>
       <p>     Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    </article>
    </section>
    - This CSS will only color red the paragraph that is the direct child of <section id="products">. The <p> inside <article> will not be affected.

    Sibling Selector

    What if we want to select elements that are siblings of each other?
    For that, we use the + (adjacent sibling) operator between the selectors. It will select the element that comes immediately after the first sibling.
    CSS CODE:
    #products + p {
       color: red;
    }
    HTML CODE:
    <section id="products">
        <p>     Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    <article>
        <p>     Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    </article>
    </section>
        <p> This paragraph is the direct sibling of the section element. </p>

    All Siblings Selector

    If we want to select all matching siblings that come after a <section> element, we use the ~ (tilde) selector.
    👉 But if we use the + (plus) selector, it will only target the first direct matching sibling.
    CSS CODE:
    #products ~ p {
       color: red;
    }
    HTML CODE:
    <section id="products">
    <p> Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    <article>
    <p>     Lorem ipsum dolor, sit amet consectetur adipisicing. </p>
    </article>
    </section>
    <p> This paragraph is the direct sibling of the section element. </p>
    <p> This paragraph is also the direct sibling of the section element. </p>
        - This CSS will make all <p> tags that come after the section turn red.

    Relational Selectors

    Relational selectors give cleaner code because we don’t need to assign id or class to many HTML elements.
    But there are two problems with relational selectors:
       1. They can be fragile.
       2. They are slower than basic selectors.
    Fragile means these selectors depend on the position of an element in the DOM. If you move elements around, the rules may break.
    How browsers read relational selectors
    For example:
    CSS CODE:
       #products ~ p
       - We (humans) read it left to right: Select all <p> elements that are siblings of #products.
       - The browser reads it right to left: It first finds all <p> elements on the page, then checks if each one is a sibling of #products.
    If there are hundreds or thousands of <p> tags, the browser will first select all of them, then discard the ones that don’t match this wastes performance.
    Quote by Donald Knuth:
    “Premature optimization is the root of all evil.”

    So, if you’re confident that the structure of your page (element positions) will not change, you can use relational selectors. Otherwise, it’s safer and faster to use id or class selectors.

    First & Last Child

    In the example below, if we want to select the first paragraph inside the <article> element, we can give it an id or class, but there’s another way. We can use a pseudo-class selector like :first-child.
    Just focus on the selector, not the CSS property.
    A pseudo-class selector is written with a colon : followed by its name.
    - :first-child means the very first child inside a parent. It doesn’t matter if it’s a paragraph, a heading, or something else.
    - If later we add a new element at the top of the <article>, that will become the first child instead.
    CSS Code:
    article :first-child {
       font-size: 140%;
       font-style: italic;
    }
    HTML Code:
    <article>
       <p>Lorem ipsum dolor sit amet.</p>
       <p>Lorem ipsum dolor sit amet. </p>
    </article>
    Similarly, there is the :last-child pseudo-class, which targets the last child inside a container.
    ⚠️ Keep in mind: :first-child and :last-child can be a bit fragile. If you add or move elements, the “first” or “last” child changes, and your CSS rule may no longer apply where you expect.

    First & Last Of Type

    By type matching, we can select elements based on their type (like headings, paragraphs, lists, etc.) inside a parent element.
    The :first-of-type selector is used to select the first element of a specific type inside a parent, no matter what other elements are around it.
    CSS Code:
    article :first-of-type {
       font-size: 140%;
       font-style: italic;
    }
    HTML Code:
    <article>
    <h2>NaseebCodeStudio</h2>
    <p>Lorem ipsum dolor sit amet. </p>
    <p>Lorem ipsum dolor sit amet. </p>
    </article>
    In this case, :first-of-type will select the first heading (h2), because it’s the first element of its type inside <article>.
    (Target only first paragraph)
    article p:first-of-type {
       font-size: 140%;
       font-style: italic;
    }
    This will style only the first <p> element inside the <article>.
    :last-of-type
       The :last-of-type selector works the same way but starts counting from the bottom of the parent container. It selects the last element of a specific type.

    Difference Between :first-child / :last-child and :first-of-type / :last-of-type

       - :first-child / :last-child 👉🏻 Looks at the position of the element as a child.
    Example: p:first-child means the first child must be a paragraph. If another element (like <h2>) comes before it, the paragraph will not be selected.
       - :first-of-type / :last-of-type 👉🏻 Ignores position and only checks element type.
    Example: p:first-of-type will always select the first <p> inside the parent, even if it’s not the very first child.
    In short:
        - Child selectors = depend on order (position).
        - Type selectors = depend on type (tag name).

    Quite often, we face a situation where more than one CSS rule targets the same element, and these rules can conflict. So, how does the browser decide which rule to apply? That’s where CSS specificity (or “weight”) comes in.

    Let’s create an example:
    HTML Code:
    <article>
       <h1 class="highlight">    NaseebCodeStudio</h1>
    </article>
    CSS Code:
    h1 {
    color: dodgerblue;
    }
    .highlight {
    color: red;
    }
    Here, both rules target the <h1> element. Which one will apply? The class selector .highlight is more specific than the element selector h1, so the text will be red.
    You can also target the same element using an ID selector. For example, if we give the <h1> an id, then the ID selector will override the class selector, because ID selectors have higher specificity.
    Think of specificity like a triangle:
        - At the top = ID selectors (strongest, unique only one ID per page element).
        - Middle = Class and attribute selectors.
        - Bottom = Element selectors (weakest, since we can have many elements of the same type).
    We can also make a selector more specific by combining them. For example:
    article h1.highlight {
       color: green;
    }
    This means: Select the <h1> inside <article> with the class highlight. This is more specific than just .highlight or h1.
    In VS Code, if you hover over selectors, you’ll see specificity values as three numbers:
        - ID selectors = 100
        - Class/attribute selectors = 10
        - Element/type selectors = 1
    If two selectors have the same specificity, then the last one written in your CSS file will be applied.
    When you right-click an element in the browser and choose Inspect, you’ll see the Styles tab.
        - The first styles usually come from your own CSS file.
        - Next, you may see styles from libraries (like Normalize.css).
        - Finally, you’ll see the browser’s default styles, called the user-agent stylesheet. These are the basic styles the browser applies if you don’t define your own.

    Specificity Numbers

    The !important keyword has the highest specificity compared to all other selectors.
    CSS CODE
    h1 {
       color: blue !important;
    }
    Even if the h1 has a class or an ID selector with different styles, the !important rule will still apply, and the text color will be blue.
    We use !important when we want to force a style to override all other rules.
    ⚠️ But using !important is considered bad practice because it breaks the normal specificity rules. This makes your CSS harder to read, debug, and maintain.
    Specificity values:
       - h1 {} 👉🏻 specificity 1
       - .className {} 👉🏻 specificity 10
       - #idName {} 👉🏻 specificity 100
       - #idName.className {} 👉🏻 specificity 110
       - h1#idName.className {} 👉🏻 specificity 111
    Bad practice example (too complex and hard to maintain):
    html body #featured h2#products.highlight {}
    This selector is too long and complicated, so it should be avoided.

  • One of the most important concepts in CSS is inheritance. Some CSS properties automatically inherit their values from the parent element.

    Inherit

    HTML CODE
    <p> We Are Learning <strong>HTML</strong> from NaseebCodeStudio. </p>
    CSS CODE
    p{
       color: dodgerblue;
    }
    When we look at the result, the child element <strong> inside a paragraph <p> inherits the text color from its parent. By default, the <strong> element (child) gets the same color as the paragraph (parent). You can check this using browser DevTools, where you’ll see that the color is inherited from the <p> tag.
       - We can explicitly set the <strong> element to a different color, for example:
    strong {
       color: dodgerblue;
    }

    Initial

    But what if we want to stop inheritance and reset the color to its default value?
    In that case, we can use the initial value:
    strong {
       color: initial;
    }
    The initial keyword resets the property to its default value, meaning it will not inherit the style from the parent element.
        - Properties that do not inherit by default
        - Not all CSS properties are inherited. For example:
    p {
       border: 2px solid red;
    }
    The <strong> element inside the <p> will not get its own border. It makes sense otherwise every child would get the same border, which would be messy.
    But if we want to force inheritance for a property that normally doesn’t inherit, we can use the inherit value:
    strong {
       color: initial;
       border: inherit;
    }
    Which properties are inherited?
    There’s a long list of inherited properties, and most people don’t memorize them. You’ll naturally learn them while working on projects.
    Generally, typography related properties (text and font styles) are inherited, such as:
       - color
       - font and font-family
       - font-size
       - font-style
       - line-height
       - text-align
       - letter-spacing
    In short: Text and font-related styles are inherited; layout and box-model styles (like borders, margins, and padding) are not.

    RGB Colors

    p{
       color: rgb(255, 0, 0);
    }
    RGB stands for Red, Green, and Blue.
    Each of these colors takes a value between 0 and 255:
        - 0 means no color (black).
        - 255 means full color (brightest).
    By mixing different values of red, green, and blue, we can create about 16.7 million colors. 🎨
       - To use RGB in CSS, we have a function called rgb().
       - The first value is for red
       - The second value is for green
    The third value is for blue
    (Values are written with commas.)
    Examples:
       - rgb(255, 0, 0) = Pure Red
       - rgb(0, 255, 0) = Pure Green
       - rgb(0, 0, 255) = Pure Blue
    Quick Tip: Think of RGB like mixing light turn all three to 0 and you get black, set all three to 255 and you get white.

    RGBA Colors
    rgba() is just like rgb(), but it has one extra value called Alpha.
        - R = Red (0–255)
        - G = Green (0–255)
        - B = Blue (0–255)
        - A = Alpha (0–1) controls transparency
    Alpha value details:
        - 1 Fully visible (no transparency)
        - 0 Fully transparent (invisible)
        - 0.5 50% transparent (see-through effect)
    Examples:
        - rgba(255, 0, 0, 1) Solid Red
        - rgba(255, 0, 0, 0.5) Half-transparent Red
        - rgba(0, 0, 255, 0.3) Light transparent Blue
        - rgba(0, 255, 0, 0) Fully transparent Green (invisible)
    Quick Tip: Use rgba() when you want a color that blends with the background, like in overlays, shadows, or buttons with transparency effects.

    HEX Colors

    🔢 Number Systems in CSS Colors
    1. Binary (Base-2)
          - Uses only 0 and 1.
          - Computers understand everything in binary (on/off, true/false).
    2. Decimal (Base-10)
          - Our everyday number system.
          - Uses digits 0–9.
          - Example: 255 (the maximum value for RGB colors).
    3. Hexadecimal (Base-16)
          - Uses digits 0–9 and letters A–F (where A=10, B=11 … F=15).
        - Very common in web development for representing colors because it’s shorter than writing long decimal values.

    🎨 Hex Color System in CSS
    In CSS, hex colors start with # and usually have 6 characters (3 pairs): #RRGGBB
          - AA = Alpha (00 = fully transparent, FF = fully visible)
    Examples:
    #FF000080 👉🏻 Red with 50% transparency
    #0000FF33 👉🏻 Blue with ~20% transparency
    Quick Tip:
          - HEX is just another way to write colors (shorter than RGB).
          - Always remember: it’s RR GG BB Alpha (optional).

    🎨HSL Colors

    HSL stands for Hue, Saturation, Lightness.
          - hsl(hue, saturation, lightness)
    Position of values:
    1. Hue: The base color on the color wheel (0–360°).
          - 0 = Red, 120 = Green, 240 = Blue.
    2. Saturation: Intensity of the color (0% = gray, 100% = full color).
    3. Lightness: Brightness of the color (0% = black, 50% = normal, 100% = white).
    Example:
          hsl(0, 100%, 50%) Pure Red
          hsl(120, 100%, 50%) Pure Green
          hsl(240, 100%, 50%) Pure Blue

    🎨 HSLA Colors

    HSLA is just like HSL but with an extra Alpha value for transparency.
          - hsla(hue, saturation, lightness, alpha)
    Position of values:
    1. Hue (0–360°)
    2. Saturation (0%–100%)
    3. Lightness (0%–100%)
    4. Alpha (0–1 transparency)
    Example:
          hsla(0, 100%, 50%, 0.5) Half-transparent Red

    🎨 HWB Colors (Newer CSS Color System)
    HWB stands for Hue, Whiteness, Blackness.
          - hwb(hue whiteness% blackness% / alpha?)
    Position of values:
    1. Hue: Base color (0–360° on color wheel).
    2. Whiteness: How much white is mixed in (0% = no white, 100% = full white).
    3. Blackness: How much black is mixed in (0% = no black, 100% = full black).
    4. Alpha (optional): Transparency (0–1).
    Example:
          hwb(0 0% 0%) Pure Red
          hwb(0 0% 0% / 0.5) Half-transparent Red
          hwb(200 30% 20%) Blue with some white and black

  • With 🌈gradients, we can create a smooth transition between two or more colors.
    Technically, gradients are treated as images in CSS. That’s why we cannot use background-color for gradients.
    Instead, we use:
          - background-image for gradients only.
       - or the shorthand background to set both colors and images (including gradients).
    Quick Tip: Remember, colors = background-color, but gradients = background-image.

    Linear Gradient🎨

    A linear gradient creates a smooth color transition in a straight line (top to bottom, left to right, or at any angle).
    CSS CODE:
    div{
          width: 300px;
          height: 300px;
          background: linear-gradient(direction, color1, color2, ...);
    }     1. Default Gradient (Top to Bottom)
    If you don’t give a direction, the gradient goes from top to bottom.
          background: linear-gradient(red, yellow);
    👉🏻 Starts with red at the top and moves to yellow at the bottom.
    2. Direction with Keywords
    You can set the direction using keywords like to right, to left, to top.
          background: linear-gradient(to right, blue, pink);
    👉🏻 Gradient goes from blue (left) to pink (right).
    3. Direction with Angles
    You can also use angles (0° to 360°).
          - 0deg = bottom to top
          - 90deg = left to right
          - 180deg = top to bottom
          - 270deg = right to left
          background: linear-gradient(90deg, green, orange);
    👉🏻 Gradient goes left to right.
    4. Multiple Colors
    You can add more than two colors.
          background: linear-gradient(to right, red, yellow, green);
    👉🏻 Smoothly blends from red to yellow to green.
    5. Using Percentages / Color Stops
    You can control where each color starts or ends.
          background: linear-gradient(to right, red 20%, yellow 50%, green 80%);
    👉🏻 Red covers the first 20%, Yellow up to 50%, Green up to 80%.
    6. Repeating Linear Gradient
    If you want a striped effect, use repeating-linear-gradient().
    background: repeating-linear-gradient(
          45deg, /* angle */
          red, /* start */
          red 10%, /* red covers first 10% */
          yellow 10%, /* yellow starts at 10% */
          yellow 20% /* yellow ends at 20% */
    );
    👉🏻 This repeats red and yellow stripes diagonally.
    Quick Tip:
          - Use linear-gradient() for smooth transitions.
          - Use repeating-linear-gradient() for patterns/stripes.
          - Play with angles + percentages to control the design.

    🎨 Radial Gradients

    A radial gradient is a smooth color transition that starts from the center and spreads outward in a circle or ellipse.
    Think of it like dropping paint in the middle of a page and watching it spread out in rings.
    CSS CODE
    div{
          width: 500px;
          height: 500px;
       background-image: radial-gradient(shape size at position, color1, color2, ...);
    }
    1. Shapes
    - Circle: Gradient spreads evenly in all directions (perfect circle).
          radial-gradient(circle, red, blue);
    - Ellipse Gradient stretches more in width or height (oval shape).
          radial-gradient(ellipse, red, blue);
    2. Position
        - We can control where the gradient starts using the at keyword.
          radial-gradient(circle at center, red, blue); /* Default center */
          radial-gradient(circle at top left, red, blue);
          radial-gradient(circle at bottom right, red, blue);
    👉🏻 Positions can be keywords (center, top, left, etc.) or percentages (20% 70%).
          - First value = x-axis (left to right).
          - Second value = y-axis (top to bottom).
          radial-gradient(circle at 30% 70%, red, blue);
    3. Color Stops & Percentages
        -You can control where colors change with percentages.
          radial-gradient(circle, red 20%, yellow 50%, blue 100%);
          - Red ends at 20% of the radius.
          - Yellow ends at 50%.
          - Blue fills the rest.
    4. Repeating Radial Gradient
    A repeating version creates patterns instead of a smooth single transition.
         background-image: repeating-radial-gradient(circle, red 0%, yellow 10%, blue 20%);
    👉🏻 This pattern will keep repeating infinitely across the background.

    Quick Tip:
          -Use circle when you want a perfect round gradient.
          -Use ellipse for stretched designs.
          -Use percentages to control where each color starts and ends.
        -Use repeating radial gradients for fun patterns like ripples or target-like effects.

    You can use free online tools to create radial or linear gradients without any coding. Just pick your colors, generate the gradient, and copy the code into your CSS file. We’ve already covered useful resources and links in the color section.

    div{
          width: 300px;
          height: 300px;
          background-color: red;
          border: 5px solid red;
    }
    1. Border Shorthand
        - Instead of writing multiple properties, we often use the shorthand:
        border: 2px solid red;
    Here’s what each part means:
          2px: border-width
          solid: border-style
          red: border-color
    📝 You can write them separately (border-width, border-style, border-color), but shorthand is cleaner and used most often.
    2. Borders on Each Side
        - You can also apply a border to each side individually:
          border-top: 5px solid red;
          border-right: 5px solid red;
          border-bottom: 5px solid red;
          border-left: 5px solid red;
    💡 Tip: In VS Code (or most editors), you can type a property and press Ctrl + Space to see available values.
    3. Multiple Values (Clockwise Rule – TRBL)
        - When you give 4 values, they are applied in clockwise order:
          border-width: 10px 20px 15px 30px;
          border-style: solid dotted dashed groove;
          border-color: red green blue yellow;
    ~ Top = first value
    ~ Right = second value
    ~ Bottom = third value
    ~ Left = fourth value
    👉🏻 Easy way to remember → TRBL = Top, Right, Bottom, Left
    4. When Fewer Values Are Given
        - If you don’t give all 4 values, CSS automatically fills in the missing ones:
    ~ 2 values
          border-width: 10px 20px;
    = Top/Bottom = 10px, Left/Right = 20px.
    ~ 3 values
          border-width: 10px 20px 15px;
    = Top = 10px, Left/Right = 20px, Bottom = 15px.
    ~ 1 value
          border-width: 10px;
    = All four sides = 10px.
    Key Takeaway You have full control over:
          - Border width
          - Border style
          - Border color
    And you can set them either all at once (shorthand) or individually (longhand).

    Outline

    Outline = A line drawn outside the element’s border.
        - Unlike border, it does not take space it just sits outside the element.
        - To create extra gap/space between the border and the outline, we use the property outline-offset.
    Example outline-offset:
    p {
          border: 2px solid black; /* normal border */
          outline: 3px solid red; /* outline outside the border */
        outline-offset: 5px; /* gap between border and outline */
    }
          - Border = black line around the element.
          - Outline = red line outside the border.
          - Outline-offset: 5px = creates a visible gap (space) between border and outline.
    Quick Tip:
    Think of an outline like a highlighter glow around a box.
    If you add outline-offset, it’s like pushing the highlighter further away from the box to make it stand out.

    Border Radius

    The border-radius property controls the corners of a box.
    It lets you make corners rounded, or even turn a square/rectangle into a circle or ellipse.
    Example 1: Same radius for all corners
    box {
    width: 300px;
    height: 300px;
    background-color: red;
          border-radius: 50px;
    }
    All four corners will have a radius of 50px (equally rounded).
    Example 2: Two values (diagonal pairs)
          border-radius: 30px 50px;
          - Top-left: & bottom-right: 30px
          - Top-right: & bottom-left: 50px
    So corners are paired diagonally.
    Example 3: Circle shape
    If the element has the same width and height (a perfect square), we can turn it into a circle:
          border-radius: 100%;       - 100% makes it a perfect circle.
    (50% also works, but 100% is safer and recommended.)
    Quick Tip:
    Use px values for soft, rounded corners.
    Use 50% or 100% on a square element to make a circle.
    Use different values to create ellipses or unique shapes.

  • Shadows🌟

    Basic Shadow
          box-shadow: 10px 10px 10px red;
    In CSS, we can easily add a shadow to any element using the box-shadow property.
    If you want to add a shadow to an image (especially PNG images with transparent backgrounds), you can also use filter: drop-shadow(). Both work in a similar way, but most of the time we use box-shadow for regular elements.
    🛠 How box-shadow Works
    The box-shadow property takes several values in order:
    1. Horizontal Offset: moves the shadow left or right.
          - Positive value (10px) = moves shadow to the right.
          - Negative value (-10px) = moves shadow to the left.
    2. Vertical Offset: moves the shadow up or down.
          - Positive value (10px) = moves shadow down.
          - Negative value (-10px) = moves shadow up.
    3. Blur Radius → controls how soft or blurred the shadow looks.
          - Larger value = more blur.
          - Example: 10px = soft shadow.
          - (Optional, can be skipped.)
    4. Spread Radius: controls how much the shadow expands or shrinks.
          - Positive value = shadow grows bigger.
          - Negative value = shadow shrinks.
          - (Optional, can be skipped.)
    5. Color: the color of the shadow.
          - Example: red, black, rgba(0,0,0,0.5)
    Example 1: Basic Shadow
    div {
         width: 300px;
         height: 300px;
         background-color: gold;
         box-shadow: 10px 10px 10px red;
    }
      - 10px right,
      - 10px down,
      - 10px blur,
      - red color.
    Example 2: Shadow on All Sides (Trick)
    If you want the shadow on all sides, set both horizontal and vertical values to 0, and then use blur and spread.
          box-shadow: 0 0 10px 5px red;
    This creates an even shadow around the element.
          box-shadow: 0 0 10px 5px black;
    This makes a gold box with a nice soft black shadow all around.

    Quick Tip:
      - Horizontal + Vertical: moves the shadow.
      - Blur: makes it soft.
      - Spread: makes it bigger.
      - Color: gives style.

  • 📖Terms

     - Embedded Stylesheets: CSS written inside the <style> tag in the HTML document.
     - External Stylesheets: CSS written in a separate .css file and linked with <link>.
     - Inline Styles: CSS written directly inside an HTML tag using the style attribute.
     - Separation of Concerns: Best practice of keeping HTML (content) separate from CSS (style).
     - Inheritance: Some CSS properties (like color, font-size) pass down from parent to child elements.
     - Selectors: Patterns used to target HTML elements.
     - Selector Specificity: Priority rules for which CSS style is applied when multiple selectors target the same element.
     - Relational Selectors: Select elements based on their relationship to other elements (parent, child, siblings).
     - Pseudo-class Selectors: Target elements in a specific state (e.g., :hover, :first-child).
     - Pseudo-element Selectors: Style a part of an element (e.g., ::before, ::after, ::first-letter).
     - Hexadecimal Colors: Colors represented with #RRGGBB values (e.g., #ff0000).
     - RGB Colors: Colors defined by red, green, and blue values (rgb(255, 0, 0)).
     - HSL Colors: Colors defined by hue, saturation, and lightness (hsl(0, 100%, 50%)).
     - Linear Gradients: Smooth color transitions along a straight line.
     - Radial Gradients: Smooth color transitions in a circular or elliptical shape.
     - Normalizing CSS: Using a “reset” or “normalize” stylesheet to make styles consistent across browsers.

    Summary

    CSS styles can be applied in three ways: inline, embedded, and external.
    Order of importance: Inline > Embedded > External (but use external stylesheets for maintainability).
    Elements can be targeted using selectors: type, class, ID, attributes, or relationships.
    Relational selectors (parent-child, sibling) can be fragile — use them carefully.
    Pseudo-classes (e.g., :first-child, :nth-child(odd)) let you style elements based on state or position.
    Pseudo-elements (e.g., ::before, ::after) let you style parts of elements.
    Specificity decides which CSS rule wins when multiple rules target the same element:
        - ID > Class/Attribute > Element.
    Some properties (like fonts and text color) are inherited by child elements.
        - Use initial to stop inheritance.
        - Use inherit to force inheritance.
    Colors can be defined using names, HEX, RGB/RGBA, or HSL/HSLA.
    RGBA and HSLA include an alpha channel for transparency.
    Gradients are created using linear-gradient() or radial-gradient() and are treated as images.
    Borders can be customized with shorthand (border) or detailed properties (border-width, border-style, border-color).
    Shadows (box-shadow, text-shadow) add depth and highlights to elements.
