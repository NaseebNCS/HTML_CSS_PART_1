  • Meta Character set
    The <meta charset> element is used to define the character set of a website.
    Computers don’t actually understand letters like A, B, C, or NCS. They only understand numbers, which are represented in binary (0s and 1s). A character set is a system that maps each character to a numeric value so the computer can display it correctly.
    The first widely used character set was ASCII (American Standard Code for Information Interchange). ASCII could only represent English characters, so it was very limited.
    Over time, new character sets were created to support more symbols and international languages. Today, the most commonly used character set is UTF-8 (Unicode Transformation Format), which can represent almost all characters in the world.
    By using the <meta charset="UTF-8"> element, we tell the browser which character set our HTML document is using.

    Meta Viewport
    The viewport is the visible area of a webpage. On mobile devices and tablets, the viewport is smaller, while on computers it is larger.
    On a desktop, we can test different viewport sizes by simply resizing the browser window.
    The meta viewport tag helps control how a webpage looks on different devices. For example:
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    width=device-width tells the browser to match the screen’s width.
    initial-scale=1.0 sets the default zoom level.
    We use the viewport meta tag so our page looks good and responsive across all devices.

    Absolute VS Relative

    A relative URL starts from the location of the current page.
    If both pages are in the same folder, you can access the other page just by typing its name and extension, for example: secondPage.html
    If the page is inside a child folder, you write the folder name first, then the page name: NCS_Folder/secondPage.html
    If the page is in the parent folder (one level up), use ../ before the page name. For example: ../secondPage.html
    If the page is many levels up, you repeat ../ as many times as needed. For example: ../../../secondPage.html three levels up.
    Note: This can look messy and hard to read. That’s why we sometimes use an absolute URL.
    An absolute URL starts from the root of the website by using /. It points directly to the exact page, no matter where the current file is located. Example: /secondPage.html
    In simple words:
    - Relative links are used for pages in the same project or folder structure.
    - Absolute links always start from the root of the website or Linking external Pages from other URLs like from youtube.com, google.com, etc.

  • Creating a Table in HTML

    To create a table, we use the <table> element, which is used for showing tabular data.
    In the past, tables were also used to create page layouts, but today that is considered bad practice, because we now have better tools like CSS Grid and Flexbox for layouts.
    Now, tables should only be used to display tabuler data.
    A table is made up of rows and cells:
    - To create a row, we use <tr> (table row).
    - Inside a row, we add cells using <td> (table data) or <th> (table heading).
    - The first row of a table is usually the header row, where we use <th> instead of <td>.
    - For styling, always use CSS, but to quickly see borders while learning, we can use the border="1px" attribute.
    Example:
    <table border="1px">
     <tr>
       <th>Category</th>
       <th>Amount</th>
     </tr>
     <tr>
       <td>Marketing</td>
       <td>$100</td>
     </tr>
     <tr>
       <td>Accounting</td>
       <td>$200</td>
     </tr>
    </table>

    👇Result
    Category Amount
    Marketing $100
    Accounting $200

    Structuring a Table

    The above table works fine, but to make it more meaningful for search engines and accessible for screen readers, we divide a table into three sections:
    1. <thead> Table Header
    2. <tbody> Table Body
    3. <tfoot> Table Footer
    Example with sections:
    <table border="1px">

    <thead>
    <tr>
       <th>Category</th>
       <th>Amount</th>
    </tr>
    </thead>

    <tbody>
    <tr>
       <td>Marketing</td>
       <td>$100</td>
    </tr>
    <tr>
       <td>Accounting</td>
       <td>$200</td>
    </tr>
    </tbody>

    <tfoot>
    <tr>
       <th>Total</th>
       <td>$300</td>
    </tr>
    </tfoot>

    </table>
    🔥This way, the table is well-structured, semantic, and accessible.

    👇Result
    Category Amount
    Marketing $100
    Accounting $200
    Total $300
