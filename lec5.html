• HTML elements are the building blocks of a webpage. Each element has its own behavior some start on a new line, some stay in the same line, and some can act like both depending on how you style them.

    Block Level Elements

    Behavior: Always start on a new line and take up the full width available (from left to right).
    Think of them as big boxes.
    Examples: <div>, <p>, <h1> to <h6>, <section>, <header>, <footer>, <article>, <ul>, <ol>, <li>, <table>

    Inline Level Elements

    Behavior: Stay in the same line as the text or elements around them. They only take up as much width as needed.
    Think of them as small words inside a sentence.
    Examples: <span>, <a>, <strong>, <b>, <em>, <i>, <img>, <label>

    Inline-Block Level Elements

    Behavior: They act like inline elements (stay in the same line), but you can also set their width, height, margin, and padding like block elements.
    Think of them as a mini box inside a line.
    Example: <button>, <input>, <select>, <textarea>

    Block: Big box, full width, new line.
    Inline: Small piece, same line, width fits content.
    Inline-block: Small box, same line, but you can control size like a block.

    Testing Behaviour

    Open a Website
    - Go to any website (Google, YouTube, an e-commerce site or run your code).

    Right-Click Inspect
    - Right-click on any part of the page.
    - Select Inspect (or press F12).
    - he Developer Tools will open.

    Select an Element
    - Use the small mouse pointer icon (top-left in DevTools).
    - Hover and click on a heading, paragraph, link, button, or image.

    Check Display Behavior
    - In the right-side panel (Styles), find the property called display.
    - It will show one of these:
    display: block; Element starts on a new line, full width.
    display: inline; Element stays in the same line, only takes space it needs.
    display: inline-block; Stays in the line but can behave like a box.

    Compare Different Elements
    - Click on a heading (h1) You’ll see it’s block.
    - Click on a link (a) You’ll see it’s inline.
    - Click on a button (button) You’ll see it’s inline-block.

    Observe Visually
    - Notice how some elements jump to a new line (block),
    - While others sit next to each other (inline/inline-block).

  • Intro In HTML, id and class are special attributes that we can add to any element. They help us identify elements and apply styles or scripts more easily.

    ID

    🆔 - id="" means identity. Think of it like your national ID card or a car’s number plate it’s unique.
    - Each element can have only one id, and the same id cannot be used for two different elements.
    Example:
    <p id="intro">This is a paragraph with a unique ID. </p>

    CLASS

    👥 - class="" is used to group elements together that share the same style.
    - Just like in school, students with different IDs can sit in the same class (Math class, English class, etc.).
    - An element can belong to multiple classes at the same time.
    Example:
    <p class="highlight">This paragraph is in the highlight class. </p>
    <p class="highlight special">This paragraph belongs to two classes. </p>

    RULES

    📏 Rules for id and class names:
    - id must be unique no two elements should have the same id.
    - Don’t start names with numbers (❌ 1box, ✅ box1).
    - id and class names must be meaningful.
    - If the name has two or more words, you can write it in:
         camelCase: myIdName
         snake_case: my_id_name
         kebab-case: my-id-name
    (❌ never use spaces like 'my id').
    - No special symbols (like @, #, !) in names.
    - For classes only, you can use spaces to add multiple classes to one element:
    <div class="box red large"></div>

    In short:
    ~ Use id for a unique element.
    ~ Use class to group similar elements (and you can apply multiple classes to one element).
