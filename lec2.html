• FIRST THING FIRST
    Click anywhere on the desktop and create a new folder. Name the folder something like HTML (or any name you prefer). Open VS Code and go to the Explorer tab located at the top-left of the VS Code window. Alternatively, click the File tab at the top header of the window, choose Open Folder(control + o), and select the folder you just created. Since the folder is empty, click on the Explorer tab and create a new file with any name, such as index.html. The .html extension tells the computer that it is an HTML file.

    HTML SYNTAX
    To tell a browser this is an html document first write <!DOCTYPE html> in index.html file, this is what we called doctype declaration in previous versoin of HTML the doctype declaratoin was so long but HTML5 solved this problem, using !doctype html we tell a browser that we are using HTML version 5
    The first element is the <html> element, which is the root element used to start a website. The second element is the <head> element, which is the head of a website and is used to provide information about the website & represent the title of a wbsite. The third element is the <body> element, which represents the content of a website. Inside the <head> element, we write the <title> element to define the website’s title. For example, Google’s title appears at the top as ‘Google’ before its logo icon.

    FINAL HTML STRUCTURE
    Your HTML final structure should look like this👇:
    <!DOCTYPE html>
    <html>
      <head>
          <title>NaseebCodeStudio<title/>
      <head/>
      <body>

        Website content here!


      <body/>
    <html/>

    Use the shortcut key (Shift + 1) and press Enter to generate the HTML boilerplate code in your HTML document. Next, right-click anywhere in the HTML document and select the Open with Live Server option to view your code in a browser. Alternatively, you can use the Live Preview icon located at the top-right corner of the VS Code window.

    URL as you run the HTML document with Live Server, you'll get a URL in the address bar of the browser. You will see an IP address: 127.0.0.1. This IP address represents the current computer, also known as the local machine. It is globally recognized as the reference to the local computer. The number 5500 is a port number where the server is listening for HTTP requests. At the end of the URL, you'll see the page or website name, such as index.html.

    YOU NEED TO KNOW
    1. The components we see in HTML are called HTML tags.
    2. HTML tags are of three types:
       a. Opening tag: <TagName> b. Closing tag: <TagName/> c. Self-closing tag: <tagName/> OR <tagName>
    '<' Less than and '>' greater than are called angle / angular brackets.
    2. An element is the combination of an opening tag + content + closing tag.
    3. HTML is case-insensitive, but it is good practice to write elements in lowercase.
    4. <html> element is parent of <head> and <body> elements
    . 5. <head> and <body> elements are siblings of each other & are childs of <html> element.

  • Code Formatting: Browsers don’t care how we format our code whether we write all the HTML elements in a single line or put each element on a separate line. But when it comes to maintaining and reading code, formatting becomes very important to keep it clean and readable.
    For this, we use a plugin called Prettier Code Formatter. You can install it from the Extensions tab. Prettier helps us format our code in a consistent way.
    To use Prettier, right-click anywhere in the document and select Format Document With…, or press Ctrl + Shift + P and choose Prettier Code Formatter.
    Do you want your code to format automatically every time you save changes? To enable this, go to: File > Preferences > Settings > Search for 'Format on Save' > Check the option. Now, whenever you save the file, the formatting will be applied automatically.

  • Open Dev Tools in Browser Using: Control + Shift + I / Right Click Choose Inspect
    You Will Get Following👇 Tabs:
    Elements Tab: Shows the building blocks (HTML) and dress (CSS) of a webpage
    Console Tab: A place where the browser talks to you and you can talk back with code.
    Source Tab: Shows all the website’s files (like a backpack full of code).
    Network Tab: Tells how fast things (images, files, data) are coming to the website.
    Performance Tab: Checks if the website is running fast or slow.
    Application Tab: Shows website storage (cookies, local data) like a lunchbox.
    Security Tab: Checks if the website is safe (lock 🔒 or not).
    Memory Tab: Watches how much brain (RAM) the website is using.
    Lighthouse Tab: Gives a report card 📋 about the website (speed, mobile-friendliness, SEO).

  • Validation: as we write code, we might make mistakes. If we don’t use the correct syntax, our web pages may not look or work as expected. In such cases, we can use a validator to find potential errors in our code.

    HTML VALIDATOR: This is a standard markup validation service. It provides free methods to check and validate our HTML code.
    You can validate in three ways:
    1. By Address, If your site is live, just enter the URL into the validator.
    2. By File Upload, Upload your HTML file and click Check.
    3. By Direct Input, Copy and paste your HTML code directly into the validator.
    After validation, you’ll see all the warnings and errors in your code, along with guidance on how to fix them.
    CSS VALIDATOR: The interface is the same as in HTML. Here, you can validate your code by entering a URL, uploading a file, or pasting code directly. After choosing any option, just click the Check button, and it will show you what needs to be fixed in your code. Always use validators they help keep your coding and website on the right track
