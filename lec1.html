Every website on a server gets an IP (Internet Protocol) address, which is like the website’s unique location.   • FRONT-END Developer Front end developer uses HTML, CSS, JS to build front-end.

    HTML stands for HyperText Markup Language. It is used to create the basic structure of a web page, just like a skeleton gives structure to the human body.
    - HyperText means text that contains links. For example, when you click a link on a web page, it takes you to another page or source.
    - Markup means adding tags to define elements on a website, such as headings, paragraphs, images, lists, tables, input fields, etc, whatever you see on a website are marked by HTML.
    CSS CSS stands for Cascading Style Sheets. It is used to style web pages and make them look attractive. It works on the structure created by HTML. The word 'Cascading' means a step-by-step or layered way of applying styles, Cascading means that when multiple styles are applied, CSS decides which one has priority (based on order, importance, and specificity)
    JavaScrip JavaScrip is used to add functionality to web pages. like making a searchbar workable and making buttons workable and adding events on a webpage etc.
    Example To create a Twitter-like post, we need a layout that includes an image, the tweet owner’s name, the tweet text, likes, shares, and comments. First, we use HTML to define the structure of the layout. Then, we use CSS to add visual effects, such as changing colors when a tweet is liked, setting text colors, adding padding, and adjusting alignment. Finally, we use JavaScript to add behavior and functionality, like the ability to like a tweet. JavaScript is a programming language while HTML, & CSS are not, meaning we can not use html, css to tell a computer what to do, we use them to define building blocks of a webpages and styling. Every webpage on an internet is build with these three languages. The better you learn these the better you become a front end developer.

  • URL: The Moment we type a name of any website that is called a URL of a website, it stands for uniform resource locator, Basically it is a way to locate resource on the internet.
    Resources are: HTML Documents, Images, Video Files, Fonts etc.

    Client Server Model: When we type a website link (URL) and press Enter, two things are working: the client (our browser) and the server (the computer that has the website). The browser asks the server, ‘Please give me this website.’ The server looks for the website and then sends it back to the browser so we can see it.

    HTTP: The communcation between client and server is formatted based on a protocol called http or hyper text transfer protcol. HTTP is a language which is used on internet for valid communcation between client and server. it is not a programming langauge it is just a plant text used over the internet. HTTPS is a secure version of HTTP. The messages between client and server are encrypted. HTTP is a set of rules that clients and servers use to communicate and exchange data.

    HTTP message:
    HERE is a single file example of http request:
    1. GET /index.html HTTP/1.3
    2. Host: www.codewithmosh.com
    3. Accept-Language: en-us
        - The first line asks for the home page of a website using HTTP version 1.3.
        - The second line shows the host, which tells where the website lives.
       - The third line shows the language the visitor understands, here it is English.
    The server gets a message and tries to understand what the client wants. The first message is called an HTTP request, and the second message is called an HTTP response.
    In the Response:
    1. HTTP/1.3 200 OK
    2. Date: 5 Jan 2025 2:16
    3. Content-Type: text/html and end with html code which shows a website.
    All you need to know is these messages are formatted with http message.

    DOM

    When a browser reads the code of a website, it builds something called the DOM (Document Object Model). This is like a map that shows all the parts of the web page, such as text, pictures, and buttons.
        - While the browser is building the page, it also asks for other resources linked to it, like images, styles, or videos. The browser asks for each resource separately, but it can ask for many things at the same time meant request are parallel, which makes the page load faster as possible.
        - When the browser recieves all the resources, it puts them together and shows you the final web page. This step is called rendering, it means showing the finished website on the screen.
    To visit any website, the process is as follows: First, we open a browser and use an ISP to connect to the internet. We request a URL, which is sent in HTTP language through the WWW path to the server. Before reaching the server, the request goes through the DNS, which maps the URL to its corresponding IP address. Once the IP is found, the server locates the requested resources and responds in HTTP language through the same path. The server sends files such as HTML, CSS, and JavaScript the core languages used to build websites. The browser use DOM formula to manage elemens or reads these files and renders the website as the final output.

  •   - HTML is a markup language used to define the structure and contents of web pages.
      - CSS are used for styling web pages.
      - JavaScript is a programming language used for making web pages interactive.
      - To view a web page, we enter its URL (Uniform Resource Locator) into the browser’s address bar.
      - To view the HTML behind a web page, we right-click on the page and select View Source or View Page Source.
      - HTTP/HTTPS is a set of rules that clients and servers use to communicate and exchange data.
      - When you visit a website, your browser (client) sends an HTTP request to the server and receives an HTTP response. The response includes an HTML document that represents the page you’re visiting. The browser reads the HTML document to construct a Document Object Model (an in-memory representation of the elements on the page). Once the DOM is ready, the browser renders (displays) the target page.
      - We can use the Network tab of Chrome DevTools to inspect HTTP requests and responses exchanged between the browser and the server.
      - An HTML document consists of a DOCTYPE declaration that specifies the version of HTML being used followed by a tree (hierarchy) of elements that define the structure and content of the document.
      - The root element in an HTML document is the html element which always includes a head and a body element. The head element contains information about the page such as its title. The body element includes the structure and content of the page.
      - Most HTML elements include an opening and closing tag.
      - We can use attributes to provide additional information about an element (like the source of an image). Attributes are coded as part of the opening tag.
    To style an element using CSS, we write a CSS rule which consists of a selector and one or more declarations.
      - The selector is used to target one or more elements. We can select elements by their type, class, ID and so on.
      - A declaration consists of a property, a colon, a value and is terminated by a semicolon.
      - Prettier is the most popular VSCode extension for formatting code.
      - Using validation services we can ensure that our HTML/CSS code is valid and follows the official rules. This helps us get better rankings in search engines.
